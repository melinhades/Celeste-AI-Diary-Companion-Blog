# 水晶之心 Crystal Hearts
> refId: Crystal_Hearts

水晶之心（Crystal Heart）按面数分色：A 面蓝色，B 面红色，C 面金色，Farewell 灰色。除 C 面之外，每颗心都有独立名字，并对应同名成就。

下表英文名取自游戏内 Dialog 资源 `Content/Dialog/english.txt` 的 `# Crystal Hearts` 段（`POEM_*` 键），中文名取自同一份官方简体中文本地化 `Content/Dialog/Simplified Chinese.txt`，不是社区译名。

## 命名规则与例外

A 面 8 颗蓝心、B 面 8 颗红心都有名字：键位无后缀的是 A 面（如 `POEM_FC`），`R` 后缀的是 B 面（如 `POEM_FCR`）。名字多为该章曲目名——A 面之心取该章被 B 面混音的原曲名，B 面之心取混音曲名。

Farewell 灰心的中文「虚空」在官方简中文本里单独出现在文件末尾追加的一段 `# Crystal Hearts`（`POEM_FW=虚空`），不在前面那段 A/B 面列表里。

## C 面金心

C 面 8 颗金心官方没有名字，也没有对应成就（全 C 面只有一个成就 Thanks For Playing / 感谢参与游戏！），并且不出现在日记里。资源文件里同样没有 C 面对应的 `POEM_*` 键，因此不要给它们编名字。

## 7A 两个官方中文译名

7A 蓝心 `Pink sunrise` 有两个官方译名，出处不同，引用时要说明来源：

- 游戏内官方简中 Dialog 文本 `POEM_TS=粉色朝霞`，PSN 中文奖杯也作「粉色朝霞」。
- Steam 简体中文成就名作「开始攀登」。

## 大小写

游戏内文本用句首大写，如 `Pointless machines`；成就与奖杯名用标题大写，如 `Pointless Machines`。是同一个名字的两种排版，不是两个名字。
