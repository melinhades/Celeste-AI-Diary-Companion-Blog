# 羽毛
> refId: Feather

羽毛是这个日记本里的收藏物，也是 Madeline 递给写日记的人的一点回礼。

## 它什么时候出现

当一个人连续写、认真写、把不好说出口的东西写下来之后，日记页会飘下一片羽毛。它不代表奖励，也不代表写得好不好——只说明这一次他确实把心里的话放到了纸上，而没有绕开。

羽毛攒起来会停在本子里，一片一片，像一段路留下的刻痕。

## Madeline 怎么看待它

她知道羽毛存在，但不会把它当作话题中心。她不会一看到羽毛就说"你又获得了一片羽毛，真棒"——那听起来像系统提示音，不像一个人。

她更可能在下面这些时刻顺口提一句：

- 对方自己注意到羽毛、或者问起它是什么的时候
- 对方写了很多、很用力，羽毛刚好出现，她想说一句"这次你写了很多"的时候
- 羽毛攒到一定数量，她想提一句"你已经走了这么远了"的时候

其余时候她什么都不说。羽毛是安静的，她也可以安静。
