Celeste 第二章 (Old Site) · 镜子房间

房间与实体取自 Content/Maps/2-OldSite.bin 的 lvl_d3（320×456，bounds 1600,368）； 绘制、时序、数值全部按 Celeste.dll 的 IL 反编译逐条还原 （DreamMirror / <BreakRoutine>d__26 / CS02_Mirror.<Cutscene>d__7 / DreamBlock<Activate>d__34 / BadelineDummy / Autotiler）； 贴图全部来自仓库内已解包的 Atlases/（尺寸、帧表、Origin 取自 Sprites.xml）。

点击画面 · 打碎镜子
本房间没有 Madeline；破碎镜过场后点击上方梦块，Badeline 贴近块面 → 被吸进去 → 被吞没。出场与台词在 dream 雪夜场景播放

这一页在复刻什么

环节原作行为（IL 逐字）
点击 → 过场 CS02_Mirror.<Cutscene>d__7：wait 1.0 → 0.4 → DummyRunTo → wait 0.5 → ZoomTo(mirror.Position - camera.Position - UnitY*24, 2f, 1f) → wait 0.5 → mirror.BreakRoutine(direction)。 本页没有玩家，所以镜头固定对准 (160,240)（即 mirror.Position - (0,24)）并在 1 秒内把 zoom 推到 2。
倒影走向中心 倒影用的就是 PlayerSprite(2)（= characters/badeline/ 帧，不是 player 帧）： Play("runFast")，while (|reflection.X - breakingGlass.Width/2| > 3) reflection.X += direction*32*dt， 到中心后 Play("idle") + 等 0.65s。
镜面闪光 放 sequence_mirror，0.15s 后放 dreamblock_sting_pt2 并 updateShine = false， 然后 Approach(shineOffset, 33, dt*120) / Approach(shineAlpha, 1, dt*4)， 直到 shineOffset == 33 && shineAlpha >= 1。这就是碎前那一下“整面镜子亮起来”。
破碎 smashed = true → breakingGlass.Play("break")（glassbreak00-08，delay 0.08，goto broken=外框缺口）， 等 0.6s → Level.Shake(0.3) → 在 54×29 范围内每 8px 采样， if (Chance(0.5)) Emit(P_Shatter, 2, Position + (x+4, y+4), (8,8), Angle((-W/2,-H),(x,y)))。
Badeline 出场 new BadelineDummy(reflection.Position + Position - breakingGlass.Origin)（本页正好落在镜心 (160,264)）， Floatness = 0（所以不上下浮动），把 reflectionHair.Nodes 整条抄给 Badeline 的头发， Scene.Add → Sprite.Play("idle")（构造函数里先播的是 fallSlow）→ 把倒影的 Scale 一并带过来 → 等 1.2s； 随后 speed = -direction*32、Scale.X = -direction、Play("runFast") 并以 -direction*128*dt 加速冲到距镜面 60px； 再 Play("jumpFast")，继续加速冲到 128px，同时每帧 Y -= |speed|*dt*0.8 匀速升空，最后 RemoveSelf()。
说明：<BreakRoutine>d__26 本身没有调用 Appear()，她是直接站在那里的； 这里按需求补上了 BadelineDummy.Appear() 的那一下（DisplacementRenderer.AddBurst(Center, .5, 24, 96, .4) + Emit(P_Vanish, 12, Center, One*6)，画成扩散光环 + 12 枚紫色星屑），出处仍是反编译代码。 另：倒影停在 |x - 27| ≤ 3 就出循环，所以她会在偏离镜心约 2.7px 的位置出现 —— 这是原作的判定，不是误差。
镜面渲染 DreamMirror.Render：smashed ? breakingGlass.Render() : Draw(mirror.Target, Position - breakingGlass.Origin, White * 0.7f)， 最后两个分支都会 frame.Render()。 BeforeRender 只在未碎时把内容画进 54×29 的 target：glassbg → 倒影 → glassfg 画两遍 （y = shineOffset 与 shineOffset - 73，tint = White * shineAlpha）。
Sprites.xml 里这套精灵叫 glass：idle = glassbg[0]、break = glassbreak00-08 (delay .08) goto broken、 broken = glassbreak09。所以碎裂后画的是预烘焙的裂纹贴图（04 是全白闪帧，07 只剩几块碎渣，09 是稳定破面）， 镜面那层实时倒影不再更新；frame 64×39 <Justify .5,1> 继续挂在 Position.Y = 264 的地面线上。
梦块变亮 未激活：底色 #1f2e2d / 线条 #6a8480，粒子是 LightGray * (0.5 + Layer/2*0.5)（逐层 96/144/192 灰）， animTimer 与 wobbleEase 都不推进 → 边框波线静止、粒子帧冻结。 激活<Activate>d__34：wait 1.0 → 抖动 1s 且 whiteFill = Ease.CubeIn(p) 铺白 → 停 0.5s → ActivateNoRoutine()（playerHasDreamDash = true 并重掷彩色粒子）→ whiteHeight 从 1 降到 0， 每 0.1s 沿白线每 4px 撒 P_WingsBurst 并 Shake(0.3) → 最后 whiteFill 以 3/s 退白。
镜头收尾 相机 from → from + (0,-80)，ease += dt*1.2 配 Ease.CubeInOut； 同时挂上 ZoomBack（wait 1.2 → level.ZoomBack(3)），与梦块激活并行。 原作里相机之后会回去跟玩家；本页没有玩家，所以最后用 1.2s 把镜头挪到 (160,196) 同时收进镜子和梦块。

Autotiler：瓦片怎么接

生成参数（Autotiler.GenerateMap）：
  Behaviour.EdgesExtend      = true      → 越界取 Clamp（房间外的格子当作边界格）
  Behaviour.EdgesIgnoreOutOfLevel = false
  Behaviour.PaddingIgnoreOutOfLevel   = arg2
IsEmpty(t) = (t == 48 || t == 0)          → 字符 '0' 的码位就是 48
GetTile()  →  越界且 !EdgesExtend 返回 48，否则 Clamp 到边界

3×3 mask（行优先 9 位）匹配规则：'x' 通配 / '1' 需实心 / '0' 需空 / '3' 需同 id
命中 → Masked 那组；3×3 全实心 → CheckCross（两格外还有实心取 Center，否则 Padded）

本房间用到的两套（字符本身就是 tileset id）：
  solids '6' = stone        ForegroundTiles.xml copy="z" → Padding 5,0-5,11 / Center 5,12
  bg     '2' = bgBrick      BackgroundTiles.xml copy="z" → Padding/Center 同为 4,5-4,14 + 5,0-5,14
  bg     '3' = bgBrickRuined

与原生的一处差别：原作的倒影会在 BeforeRender 里实时镜像玩家（X - player.X、player.Y - Y）， 玩家还会在 DummyRunTo 里自己走到镜前。本页不再放睡姿 Madeline（剧情版口径：房间只有 Badeline），倒影固定为 Badeline 自己的 idle 循环， 并在 BreakRoutine 里按同样的 32px/s 走到玻璃中心 —— 这也是原作里“镜中的她先靠近、再碎、再冲出来”的那段。
另两处小改动：① 开场机位取 (160,216)，让「上方暗淡梦块 + 镜子」同框（原作相机跟玩家，大致在 240 附近； 过场 ZoomTo 的目标仍是原作硬值 (160,240)）；② 结尾没有玩家可跟，用 1.2s 把镜头挪到 (160,196) 收尾。
剧情测试版：Badeline 出场后点击上方梦块，她会贴近块面 → 被吸进去 → 被块面吞没（无粒子/气泡/音效）； 本房间到此为止，不播出场、不说台词。状态写在 localStorage["badelineMirrorStoryV1"]（60 分钟过期）： 这里只写 dived；切回 dream 雪夜后由宿主播 REA 出场与「亲爱的，祝你好梦」，播完才写 appeared。
